## What is implemented

- Public Ask runs through `FireLensAgent` and an immutable exact-call
  `AgentQueryPlan`.
- Three lanes remain distinct: official live records, reviewed stable guidance,
  and labelled general background.
- Deterministic contracts own official IDs, counts, status, size, geometry,
  distance, rank, timestamps, completeness, and unavailable layers.
- Static RAG combines admitted local chunks, BM25+dense retrieval, RRF,
  reranking, packet-specific evidence, generation/compilation, and validation.
- `AskResponse` binds answer sections, claims, evidence, live results, proof
  cards, and roster/sample identity across API and UI.

## Campaign repairs

### Understanding and authority

Response-control preambles are no longer treated as places. Same-turn personal
location declarations bind without authorizing a background subrequest, and
fronted multiword/numeric B.C. communities share one generalized vocabulary
contract. The final focused typed intent/agent suite passed 284 tests plus 35
subtests.

### Official live data

Malformed rows, geometry, size, timestamps, or authoritative counts quarantine
the affected layer. Completeness requires exact equality between fetched unique
records and the published count. Named-fire lookup pages through a bounded
complete roster; closed-state matching is normalized but exact; and mixed
fire/evacuation totals add disjoint scopes. Healthy siblings and a legitimately
empty successful layer remain distinct. The final focused live/safety/
architecture group passed 122 tests plus 48 subtests using official-shaped
fixtures and `httpx.MockTransport`, not real feeds.

### Product/UI

The client counts distinct wildfire identities rather than incident/perimeter
rows, uses neutral terminology for evacuation-only or mixed results, and avoids
claiming a unique total for partial data. Mobile task order, header density,
focus/landmark semantics, and muted-text contrast were improved within the
existing Pacific design language. Vitest passed 183 tests; local axe checks had
zero automated violations at the inspected idle/live states. Human keyboard,
screen-reader, native 200% zoom, touch, and comprehension review remain open.

### Repository and evaluation infrastructure

The generated map contains 587 modules (492 Python, 87 TypeScript, 8
JavaScript), 5,758 symbols, 2,016 resolved import edges, 179 test modules, and
nine endpoints. Its validator and map-only drift check pass. `AGENTS.md`, seven
bounded repository skills, the Architecture Book, System Card, docs audit,
EvalLab, and CI/docs gates now share explicit authority boundaries.

Fifteen confirmed baseline/production failures are retained as normalized
campaign `FailureRecord`s: three at understanding/place binding, nine at the
