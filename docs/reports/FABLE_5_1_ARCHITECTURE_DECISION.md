# FireLens architecture decision (product rescue)

Date: 2026-09-03. Basis: `evals/fable51_product_rescue/architecture_inventory.md`,
`assumption_ledger.md`, reproduced runtime behaviour, and
`FABLE_5_1_ARCHITECTURE_CONTRADICTIONS.md`.

Target mental model:

```text
UNDERSTAND   question + conversation -> one Understanding (clauses, place, record reference)
BOUND        Understanding -> permitted operations (plan with exact tool calls)
EXECUTE      official layers / reviewed retrieval / general background
VERIFY       deterministic facts, evidence bindings, authority rails
PRESENT      one response: answer sections per clause outcome + sources + records
RENDER       answer first, sources inline, map/records when useful
```

The safety and authority invariants (failure ≠ zero, no personalized decisions,
no fabricated official records/quotes, model cannot widen tools or geography,
privacy) are all implemented today and are preserved. The redesign targets
*understanding*, *presentation* and *delivery*, where the evidence shows the
product fails ordinary users.
