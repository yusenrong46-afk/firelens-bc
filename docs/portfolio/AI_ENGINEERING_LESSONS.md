# Applying ideas from Chip Huyen's AI Engineering

This is our application of the book's ideas, not author endorsement. Topic mapping
is based on the author's [official repository](https://github.com/chiphuyen/aie-book)
and [table of contents](https://github.com/chiphuyen/aie-book/blob/main/ToC.md), checked
2026-09-23. Chapters 3–4 address evaluation, 5 context/prompting, 6 RAG and agents,
8 dataset engineering, 9 inference optimization, and 10 architecture and feedback.

| Lesson | Hypothesis → experiment → result → limitation → decision |
| --- | --- |
| Component and application evaluation | Routing success may hide publication failure → compare 24 frozen cases and inspect full source support, then browser smoke → offline 15/24 to 24/24 → live correctness is a separate gate → require both. |
| Context construction | Missing or excessive prior context changes the task → bag/pets and weather/located-fire sequences → narrow owner repairs fix nine frozen cases → unrelated pet travel initially exposed overreach → add independent-purpose controls. |
| RAG and data quality | Relevant text may omit a condition → assert full retained pet passage and source hash → local checks preserve its ending qualifications → stored revision is not proof of current publication validity → preserve authority labels and defer source migration. |
| Measured efficiency | Fewer lines need not mean faster inference → same ten-route workload, warm/cold measurements and provider counters → publish receipts before claiming gains → fixtures exclude remote queue/network variation → retain no unsupported speed claim. |
| Architecture and operations | Failures cross service and UI boundaries → test deadlines, unavailable states, map refresh and immutable evidence → protected controls distinguish map observations from answers → local evidence is not production qualification → staged release, identity checks and rollback. |

No finetuning, cross-request embedding cache, new model gateway or generalized
agent platform is claimed. The strongest learning evidence is a reproducible
failure, its smallest responsible repair, and a test that can still reject it.
