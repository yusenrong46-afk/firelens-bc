# Three-minute map-first demonstration

Use the bound preview or public release URL. State its commit and whether the
session uses live providers or a fixture lane. Neither path is emergency advice.
Do not imply a cached count describes conditions now.

| Time | Action | Explain |
| --- | --- | --- |
| 0:00–0:30 | Open map; inspect counts, check times and layers below/above tiles | Official records load independently of AI readiness. Missing records are not an all-clear. |
| 0:30–1:10 | Ask “What should I put in a wildfire grab-and-go bag?” | Readable original wording, authority labels and material limits. |
| 1:10–1:40 | Ask “What should I add for my dog or cat?” | Uses the actual preceding conversation. Open supporting PreparedBC passage and its locator. |
| 1:40–2:00 | Open Why, Copy and sources | Same answer snapshot, no extra provider request for inspection. |
| 2:00–2:35 | Return to map; inspect an actual record and its timestamp | Selection preserves record identity. Refresh observations do not rewrite the earlier answer. |
| 2:35–3:00 | Explain limits and reset via brand | Independent beta; official authorities decide emergencies. Broader source/quality work remains separate. |

If a provider fails, demonstrate the unavailable state and retain the failed result.
Do not manufacture prerequisite history. A saved fixture can explain the intended
workflow, explicitly labelled, but cannot replace a failed live release gate.
