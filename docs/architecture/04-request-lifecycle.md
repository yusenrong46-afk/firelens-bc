# 04 — Request Lifecycle

This is the verified public `POST /api/v1/ask` path. The row order is the diagnostic order: the first wrong structured value is the first-divergence owner.

| Stage | Owner / symbol | Input → output | Invariant | Failure / observation / tests |
| --- | --- | --- | --- | --- |
| Request bound | [`api/middleware.py`](../../src/firelens/api/middleware.py) `BoundedAnonymousRequestMiddleware` | ASGI body/client key → replayable bounded request | Guarded anonymous writes are size- and rate-bounded | 400/413/429 envelopes; instance-local rate limit; `test_request_body_middleware.py`, `test_request_guard.py` |
| Parse | [`contracts.py`](../../src/firelens/contracts.py) `QueryRequest` | JSON → normalized question, ≤6 history turns, optional coarse location/map context | Blank/extra/oversized or exact-address-like input is rejected | FastAPI validation handler; `test_api_privacy_boundary.py`, `test_public_contract_publication.py` |
| Deadline/readiness | [`api/answer_routes.py`](../../src/firelens/api/answer_routes.py) `ask`, `_answer_request` | request + runtime → execution or typed error | One public deadline; missing service is not-ready, not an empty answer | 503/timeout envelope; successful path emits endpoint operation event |
| Context correction / seatbelt | [`agent/coordinator.py`](../../src/firelens/agent/coordinator.py) `FireLensAgent.answer`; [`agent/rails.py`](../../src/firelens/agent/rails.py) | current request + bounded history → corrected or terminal request | Prohibited/personal decisions stop before tool authority; terse corrections cannot broaden prior task | Deterministic abstention/clarification; golden traces, intent and safety tests |
| Typed understanding | [`answering/intent_automaton.py`](../../src/firelens/answering/intent_automaton.py) `parse_request_intent` plus clause/location/record helpers | question/history/context → request features | Understanding proposes shape; it does not grant tools | Phrase grammars can diverge; `test_typed_intent_automaton.py`, `test_request_facets.py` |
| Authority plan | [`agent/query_plan.py`](../../src/firelens/agent/query_plan.py) `build_agent_query_plan` | typed features → frozen `AgentQueryPlan` | Exact mode, layer, geography, location, static subrequest, and tool arguments are application-owned | Terminal requires-input/redirect or bounded plan; `test_agent_query_plan.py`, `test_agent_query_plan_boundary.py` |
| Prefetch / dispatch | [`agent/prefetch.py`](../../src/firelens/agent/prefetch.py), [`agent/runtime_tools.py`](../../src/firelens/agent/runtime_tools.py), [`agent/tools.py`](../../src/firelens/agent/tools.py) | exact planned calls → typed live/static packets | Fixed vocabulary only; unplanned args and repeated dispatch are rejected; ≤4 tool calls | Policy counters/fallback reason; `test_agent_prefetch.py`, `test_intent_capability_bypass.py` |
| Official live | [`live.py`](../../src/firelens/live.py) `LiveDataService` | authorized layer/scope → records + per-layer status | Failed/malformed layer is unavailable; legitimate empty remains available zero | Limitations/unavailable layers; `test_live.py`, `test_live_qualification.py` |
| Static retrieval | [`answering/service.py`](../../src/firelens/answering/service.py), [`retrieval/pipeline.py`](../../src/firelens/retrieval/pipeline.py) | exact static subrequest → plan, hybrid retrieval, evidence packet | Stable admitted corpus only; packet identity binds selected support | Retrieval bundle errors/abstention; retrieval, corpus, evidence identity tests |
| Generation / compilation | [`answering/generate.py`](../../src/firelens/answering/generate.py), [`publication/compiler.py`](../../src/firelens/publication/compiler.py) | evidence packet → model draft or compiled claims | Tier A/B supported facts are deterministic/quote-only; background cannot cite corpus | Typed provider errors or publication handoff; publication and quote tests |
| Validation | [`answering/validate.py`](../../src/firelens/answering/validate.py), [`publication/compiled_validation.py`](../../src/firelens/publication/compiled_validation.py) | draft/claims + packet → `ValidationReport` | IDs, exact quotes, support, policy, and protected fields must pass | One bounded rewrite where eligible, otherwise fail closed; validation/repair tests |
| Composition | [`agent/compose.py`](../../src/firelens/agent/compose.py), [`contract_composition.py`](../../src/firelens/contract_composition.py) | authorized lane results + boundaries → sections/top-level answer | Pure live records are deterministic; mixed lanes stay visibly separated | Typed fallback/limitation; composition and mixed-clause tests |
| Public contract | [`contracts.py`](../../src/firelens/contracts.py) `AskResponse.validate_public_state` | composed response → validated wire model | Claim authority, live prose, section composition, result identity, proof cards, roster/sample IDs agree | Response validation error becomes sanitized error; publication/public-contract tests |
| HTTP + telemetry | [`api/answer_routes.py`](../../src/firelens/api/answer_routes.py), [`operational_logging.py`](../../src/firelens/operational_logging.py) | validated response → JSON + content-free event | Response model is final API boundary; telemetry accepts no raw content | Current gaps: some early errors lack normal success event; tool-attempt and stage latency fields are coarse; observability tests |

## Branch behavior

- Terminal plans return application-owned capability, clarification, redirect, or safety-boundary responses without evidence work.
- Pure static requests execute `StaticRAGService`; an accepted response needs no outer agent write.
- Live and selected-record responses use deterministic official-record prose when records are present.
- Mixed requests keep current records and reviewed/background information in separate `AnswerSection`s.
- Provider-requested tools are still checked against the already-frozen plan; the model cannot widen it.
