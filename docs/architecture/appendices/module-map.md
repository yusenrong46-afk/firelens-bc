## Duplicate ownership and hotspots

- Legacy [`live_answering.py`](../../../src/firelens/live_answering.py) `LiveAnswerCoordinator.answer()` still composes complete answers for many direct tests; public Ask uses `FireLensAgent`.
- [`agent/fallback_brain.py`](../../../src/firelens/agent/fallback_brain.py) re-derives static intent beside the immutable plan.
- [`apps/web/src/features/ask/proofPresentation.ts`](../../../apps/web/src/features/ask/proofPresentation.ts) repeats proof/status/freshness decisions owned by backend publication/proof contracts.
- Raw-text route, clause, place, and live-intent helpers remain distributed around the typed automaton.
- Live publication construction is split between `publication/compiler.py` and internal publication-authority helpers.

The generated map’s [`complexity.json`](../../firelens-map/complexity.json) owns current physical-line and branch-decision measurements. Concentration remains highest around typed intent, place parsing, runtime artifacts, live analysis/support, proof presentation, composition, contracts, live normalization, and query planning. These are **CURRENT-CANDIDATE-LOCAL** navigation measurements, not quality scores; the map README records their source digest.
