# Five-minute GMT demo

Use the actual app. This checklist is prepared, not a release-readiness claim.
The current source/index and release gates in [the polish record](../releases/firelens-polish.md)
must pass before presenting the revised guidance as deployed.

| Time | Task | What to demonstrate |
| --- | --- | --- |
| 0:00–1:30 | Ask “What official wildfire records are near Kelowna?” | Explain returned coverage, select one record, open the map, and show publisher update time separately from FireLens check time. Distances are straight-line calculations, not evacuation advice. |
| 1:30–3:00 | Ask “What should I pack in an evacuation kit?” | Show the answer, supporting passage and exact PreparedBC document revision. The current admitted diagram includes insurance/important papers. Distinguish an approved paraphrase from an exact quotation. |
| 3:00–4:15 | Select a returned fire and ask “What is the current status of this fire?” | Show that the selected record identity persists. Open its issuing source; do not claim missing evacuation coverage means no orders. |
| 4:15–5:00 | Briefly show the repository map and evaluation record, then Home | Explain deterministic ownership of facts and paired historical/current evidence. Home clears the draft, location and selection. |

Before the demo, check production build/deployment identity and current feed
availability. A missing layer is a useful honest limitation to explain, not a
reason to invent a record or switch to undisclosed synthetic data. If showing the
local fixture environment, label it explicitly and do not present it as live.

Positioning: evidence-bound wildfire intelligence for British Columbia, with
official records, reviewed preparedness guidance and labelled general background.
The technical value is inspectable source and identity continuity across those
lanes. FireLens does not replace issuing authorities or emergency decisions.
